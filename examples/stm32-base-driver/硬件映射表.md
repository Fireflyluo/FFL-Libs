### 背光 LEDK（重要）

| 项 | 内容 |
|----|------|
| 原理图 | TXEN(PB12)→1k→S8050(B)，E=GND，C=LEDK，LEDA=VCC |
| 故障 | PCB 封装镜像导致 **C/E 接反**，LEDK≈1.7V，灯不亮 |

### USB

| 项 | 内容 |
|----|------|
| 引脚 | PA11=DM，PA12=DP |
| 枚举 | CherryUSB CDC，VID:PID `FF55:5711` → 主机 COM6 |
| **必须** | **DP 对 3.3V 1.5k 上拉**（曾因未接导致不枚举） |
| 用途 | 写图入 W25Q（`tools/usb_upload_img.py`，单包写后 ACK） |

上传协议为 USB CDC 独占的二进制分包：主机发送一个最大 64B 的请求包后等待
`ACK/NACK`，DATA 包只在写入 W25Q 成功后才确认。调试 UART（COM4）不承担图像上传。

### 串口命令（USART1 @115200，COM4）

命令体固定为以下 **8 字节** ASCII；末尾接受 `LF`（9 字节）、`CR`（9 字节）或 `CRLF`（10 字节）。不接受旧缩写或中文命令：

| 功能 | 串口报文 |
|------|----------|
| 空袭警报 | `cmd:ARDA` + 行结束符 |
| 预先警报 | `cmd:PREA` + 行结束符 |
| 解除警报 | `cmd:ACLR` + 行结束符 |
| 停止鸣放 | `cmd:STOP` + 行结束符 |
| 图 1 / 2 / 3 | `cmd:IMG1` / `cmd:IMG2` / `cmd:IMG3` + 行结束符 |

图像只经 USB CDC 写入，不走调试 UART。

### Flash 图像槽（320×240 RGB565 = 153600B）

| 图 | 基址 | 长度 |
|----|------|------|
| img0 | `0x000000` | 0x28000 |
| img1 | `0x028000` | 0x28000 |
| img2 | `0x050000` | 0x28000 |

### 引脚冲突说明

- **SPI1 不能同时**给 LCD 与 W25Q：LCD 用默认脚 PA5/7；W25Q 只能软 SPI（PB3/4/5）。硬 SPI remap 分时**已失败**。
- J8 原理图网络是 LoRa，**当前被 ST7789 占用**；板上若仍焊 E220，PB1(DBSY/BUSY) 等可能与 LoRa 争脚。

### Flash / LCD 路径结论（2026-09-20）

- W25Q128 读写固定使用 GPIO 软件 SPI（PA15/PB3/PB4/PB5）。
- ST7789 刷屏固定使用 SPI1 TX + DMA1_CH3；两条总线分离，不做 SPI1 与 Flash 分时。
- 实板逐块比对 153600B 图像时，软件 SPI 读为 `559612 us`，GPIO + TIM2 + DMA1_CH2 读为 `2696137 us`；后者仅 DMA 翻转 SCK、CPU 仍逐位轮询采样，约慢 4.8 倍。因此已移除该实验后端及启动期擦写/扫描，默认固件不再访问测试扇区。

## 4. 外设总线一览（写驱动时用）

```text
SPI1  PA4/5/6/7  + PB0/1/12/13, PA3   →  E220 LoRa
软件 SPI PA15/PB3/4/5                 →  W25Q128
I2C1  PB8/PB9   + PB7 INT             →  SC7A20
I2C1  同上      + PB6 INT             →  J9 MPU6050
UART1 PA9/PA10  + PB14 DE             →  CH340 与 SP485（串阻复用）
UART3 PB10/PB11 + PA1 PPS             →  ATGM336H GPS
USB   PA11/PA12                       →  USB2（原生 USB）
SWD   PA13/PA14                       →  J1
```

## 5. 注意点

1. **USART1 被 CH340 和 RS485 共用**，靠 22Ω 串阻隔离；做 RS485 时要用 **PB14** 切换 DE/RE。
2. **LoRa 网络已被 ST7789 占用**（见文首「当前固件接线」）；板上若仍焊 E220，注意 PB1(BUSY) 等争脚。
3. **Flash 用 GPIO 软 SPI**，与 LCD 的 SPI1 分离；SPI1 分时和 GPIO + TIM/DMA 读实验均不进入默认固件，实测结论见上方「Flash / LCD 路径结论」。
4. **A8VG（PA8）** 参与电源路径，给 VDD 外设上电前注意电平。
5. **BOOT0** 原理图下拉；清 RDP 时需临时接 3.3V 再复位进 IAP。
6. **USB 必须 D+ 1.5k 上拉**，否则无 CDC COM 口。
7. **蜂鸣器 PB6 低电平有效**；LEDK 因 S8050 封装镜像曾异常，**现硬件接地常亮**。
